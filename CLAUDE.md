# gatherflights.com

This repository is **public**. It holds only the static marketing site served by GitHub Pages at gatherflights.com. The application, backend and planning live in a separate private repository.

## What belongs here

- Public pages: home, pricing, FAQ, privacy policy, terms, press kit.
- Public brand assets (logo, icon) and the `CNAME` file.

## What never goes here

Anything committed here is public forever, even after it's deleted, because it stays in the git history.

- Secrets of any kind: API keys, tokens, `.env` files, signing certificates, Apple `.p8` keys, Stripe keys.
- Plans, roadmaps, unreleased pricing, cost figures, vendor contracts or anything copied from the private repository.
- Personal information about anyone, including the owner's personal email, address or phone number.
- Application or backend code.

If you're unsure whether something is public, leave it out and ask.

## Site rules

- Static HTML and CSS only. No build step is needed.
- No third-party scripts, trackers, analytics, ad pixels, embedded fonts or CDNs. The site loads nothing from other domains, so visitors' browsers talk only to GitHub Pages.
- Contact links use the public business address, never a personal one.
